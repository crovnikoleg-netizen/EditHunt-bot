# Vacancy bot MVP

Telegram-бот для сбора вакансий монтажёров.

## Что работает

- профиль пользователя и статус подписки;
- демо-доступ на 7 дней для проверки сценария;
- фильтр по короткому/длинному формату;
- фильтр по качеству вакансии;
- стоп-слова;
- дедупликация вакансий;
- карточки вакансий с оценкой и кнопкой раскрытия контактов;
- приём сообщений из групп, супергрупп и каналов, куда добавлен бот;
- SQLite-хранилище.

## Запуск

Переменные окружения:

- `BOT_TOKEN` — токен Telegram-бота;
- `ADMIN_CHAT_ID` — числовой ID администратора.

```bash
python3 bot/main.py
```

Для теста от имени администратора:

1. открыть бота и отправить `/start`;
2. нажать «Продлить подписку»;
3. активировать демо-доступ;
4. выполнить `/demo`;
5. открыть `/feed`.

Чтобы бот видел обычные сообщения в группах, отключите Privacy Mode в BotFather.

## Работа без открытого Replit

Для непрерывной работы опубликуйте проект через **Publish**. Для этого проекта
выбран тип deployment `VM`: он держит Telegram polling-процесс запущенным,
поэтому бот продолжает принимать вакансии, даже когда браузер и компьютер
пользователя выключены.

При временном сбое сети или Telegram бот автоматически перезапускает polling
с увеличивающейся задержкой. SQLite-база сохраняется в `bot/vacancies.db` и
используется после перезапуска.
